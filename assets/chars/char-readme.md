# 角色资产说明

## 玩家角色

### P1 (player-p1.svg)
- 蓝色主题
- 红色帽子装饰
- 标准圆眼睛 + 高光
- 区分度：帽子的方向暗示朝向

### P2 (player-p2.svg)
- 红色主题
- 黄色围巾装饰
- 微笑嘴巴（vs P1 的平和嘴）
- 区分度：围巾在胸前飘动的感觉

## 敌人角色 (4种配色)

### Enemy-1 (紫色)
- 邪恶独眼 + 尖眉毛
- 露出尖牙的坏笑
- 红色腮红（凶恶感）

### Enemy-2 (绿色)
- 眼罩（神秘感）
- 叶子装饰（森林主题）
- 微笑（友善敌人）

### Enemy-3 (橙色)
- 独眼罩 + 面部疤痕
- 火把手持（火焰主题）
- 凶恶表情

### Enemy-4 (粉色)
- 王冠 + 蝴蝶结
- 俏皮圆嘴
- 泪痣（反差萌）

## 使用建议

每个 SVG 都是 60x60 viewBox，实际渲染时根据游戏 TILE=48 缩放即可。
建议在 Canvas 中使用 `ctx.drawImage()` 加载预渲染的 Image 对象。
