# 🫧 BubbleBlast

> 泡泡堂 Q版复刻 · A cute Bomberman-style party game, reborn with HTML5 Canvas — no Flash, no assets, no dependencies.

A from-scratch remake of the classic 4399-era Q版泡泡堂, written in vanilla JavaScript and Canvas.
Everything — characters, bombs, flames, maps and sound effects — is generated by code at runtime.

**中文说明**：经典 Q版泡泡堂的现代复刻版。纯原生 JS + Canvas 实现，零图片素材、零音效文件、零第三方库，双击 `index.html` 即可开玩。

## ✨ Features

- **Single-player campaign** — clear waves of enemies that chase you, dodge bombs, and level up through stages (3 lives, escalating difficulty)
- **Local versus mode** — P1 vs P2 on one keyboard, first to 3 round wins
- **Classic mechanics** — cross-shaped explosions, chain reactions, power-ups hidden under bricks (bomb / fire / speed), corner-slide movement
- **Advanced power-ups** — kick (boot bombs across the field), shield (6s invincibility), remote detonator (trigger bombs on demand)
- **Rotating map themes** — grassland, snowfield, desert and night palettes change every level / round
- **Smart enemy AI** — BFS pathfinding, danger-map avoidance, and it checks for an escape route *before* dropping a bomb
- **Procedural everything** — Q-version characters, particle effects and chiptune sound effects (WebAudio) are all drawn/synthesized in code
- **Responsive & fullscreen** — auto-scales to any window size with retina (HiDPI) support; press `V` or double-click to go fullscreen

## 🎮 Controls

| Action | P1 | P2 |
|---|---|---|
| Move | Arrow keys | `W` `A` `S` `D` |
| Drop bomb | `Space` | `F` |

Other keys: `1` single player · `2` versus · `P` pause · `M` mute · `V` / double-click fullscreen

## 🚀 Quick Start

Just open `index.html` in any modern browser — that's it.

Or serve it locally (recommended for mobile testing on the same LAN):

```bash
python -m http.server 8080
# open http://localhost:8080
```

## 🧱 Tech Notes

- Single canvas, fixed logical resolution (720×680) scaled to viewport with `devicePixelRatio` awareness
- Grid-based collision with per-axis movement and corner-slide assist for the classic "smooth cornering" feel
- Enemy AI: danger map (bomb blast-radius prediction) + BFS pathfinding + escape-route simulation before attacking
- WebAudio-synthesized SFX (no audio files)
